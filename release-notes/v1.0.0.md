smpmon 1.0 is the first release for Linux, macOS and Windows. It brings hardware monitoring, an editor for dashboard layouts, custom themes and configurable keys.

## Highlights

**macOS and Windows.** smpmon now runs on all three systems from a single binary without cgo. Processes are read in one pass per sample: one sysctl call on macOS and one `NtQuerySystemInformation` call on Windows. A full sweep takes a few milliseconds.

**Hardware.** New `gpu`, `sensors`, `battery` and `docker` widgets, plus two new dashboards, Hardware and Containers:
- NVIDIA GPUs on every system, through `nvidia-smi`. AMD and Intel GPUs on Linux, through sysfs.
- Temperatures and fans from hwmon on Linux, SMC on macOS and WMI on Windows. The CPU temperature also appears in the title of the `cpu` widget.
- Batteries, and Docker containers with their CPU, memory, network and disk usage.

Widgets whose data isn't available on the machine, such as a battery on a desktop, are hidden and their space goes to the others.

**Layout editor.** Press `e` to change a dashboard without writing YAML:
- split, add, delete, move and resize widgets, or drag borders with the mouse;
- change widget types and edit options in a form;
- undo, and create new dashboards.

Saving changes only that dashboard in your config file. Everything else, including comments, is kept, and the previous file is saved as `config.yaml.bak`.

**Themes.** Write your own theme in YAML; it can inherit from a built-in one. `smpmon theme export nord` prints a starting point, and `T` switches themes while smpmon is running. `general.color` forces truecolor, 256, 16 or no colors.

**Key bindings.** Every action can be rebound in the config. A `vim` preset adds `hjkl` navigation. Conflicting bindings are reported when the config is loaded, and the help screen (`?`) shows the current keys.

## Install

```sh
brew install --cask hightemp/tap/smpmon                                   # macOS, Linux
scoop bucket add hightemp https://github.com/hightemp/scoop-bucket        # Windows
scoop install smpmon
go install github.com/hightemp/smpmon/cmd/smpmon@v1.0.0                   # from source
```

## Upgrading from 0.1

Configs from 0.1 keep working. The default tab list now includes `hardware` and `containers`. If your config sets `general.dashboards`, add them there to see them.

## Known limitations

- macOS and Windows support is new and has been tested in CI only so far. Please report anything that looks wrong.
- Not supported yet: GPUs on macOS, and Docker on Windows over a named pipe (`DOCKER_HOST=tcp://…` works). Temperatures on Windows often need administrator rights.
- AMD and Intel GPU support has only been tested against recorded sysfs data.
